# 🎬 20秒CM自動生成スタジオ（Web UI ＋ Remotion）運用・カスタマイズマニュアル

イベント告知文やWebページの原稿をコピペするだけで、Googleの生成AI（`@google/genai`）と決定論的動画フレームワーク **Remotion** を連携させ、**軸ズレ・音ズレ一切なしの「20秒（4カット構成）CM動画（MP4）」** を企画・音声生成・尺計測・背景生成・インフォメーションボード合成まで一貫して制作できるスタジオです。

---

## 🚀 1. 初期セットアップ手順

### ① パッケージのインストール（初回のみ）
```bash
npm install
```

### ② `.env` ファイルの作成と `GEMINI_API_KEY` の設定
プロジェクト直下の `.env.example` をコピーして `.env` を作成し、Google AI Studio等で取得した `GEMINI_API_KEY` を設定します。

```bash
cp .env.example .env
```

`.env` の中身：
```env
GEMINI_API_KEY="AIzaSyYourActualApiKeyHere"
PORT=3000
```

> 💡 **APIキー未設定でもテスト可能！**
> `GEMINI_API_KEY` が未設定の状態でも、自動的に「モック生成モード（API消費なし）」へフォールバックし、ダミー音声の尺計測からMP4書き出しまで全機能をテストできます。

### ③ 制作スタジオ（Web UI）の起動
普段のCM制作は以下のコマンド1つで完結します：

```bash
npm run studio
```

起動後、ブラウザで **[http://localhost:3000](http://localhost:3000)** を開いてください。

## 📖 2. 【基本編】告知文コピペから20秒CMを作る4ステップ

### Step 1: イベント告知文をコピペし、モードを選んでAI構成ボタンを押す
1. 画面左側のテキストエリアに、イベント告知ページや案内文（目次や注意事項が含まれた長文でもOK）をそのまま貼り付けます。
   - 動作確認したい場合は **[📋 サンプル告知文を入れる]** ボタンを押すと「計算道場」のサンプル原稿が入力されます。
2. 作成したいCMの仕様をワンクリックで選択します：
   - **CMタイプ切替**：
     - **`📅 日付入りピンポイント告知`**：告知文から「開催日程・時間・場所・対象者・申込方法」を抽出し、シーン4で具体的な日付を告知します。
     - **`♻️ 汎用CM（日付なし）`**：具体的な日付をあえて省き、「毎月開催！」「最新スケジュールはWebへ」など常設・使い回しできる構成にします。
   - **画面比率切替**：
     - **`🖥️ 横長 (16:9)`**（1920×1080：YouTube・Webサイト・会場スクリーン向け）
     - **`📱 縦長ショート (9:16)`**（1080×1920：YouTube Shorts・TikTok・Instagram Reels・X向け）
   - **トーン選択**：
     - `🔥 熱血・スピード感` / `✨ スマート・知的` / `🔰 親しみ・安心感`
3. **[✨ AIで20秒CM構成（4カット）を自動作成]** ボタンをクリックします。

---

### Step 2: 4枚のカード（背景指示文・シーン4のインフォメーションボード）を確認・微調整する
画面中央〜右側に4カット分の絵コンテカードが並びます。

- **⏱️ リアルタイム秒数ゲージ（画面上部）**
  - 各カードのナレーション文字数から予想秒数（約6.5文字＝1秒目安＋余白）を自動計算し、`⏱️ 合計予想尺：19.5秒 / 目標 20.0秒` のように表示します。
  - 秒数オーバー時はオレンジ・赤色の警告表示に切り替わるため、ナレーションを削って20秒前後に気持ちよく収められます。
- **シーン1〜3のカード**
  - `🎙️ ナレーション`、`💥 中央デカ文字`、`🏷️ サブバッジ`、`💬 下部テロップ` を自由に編集できます。
  - `🖼️ 背景イメージ指示` は日本語で記述でき、空欄にならないようバリデーションがかかります。
- **シーン4のカード（📋 インフォメーションボード専用枠）**
  - 最終カットは画面中央に美しい要約パネル（インフォメーションボード）が出現します。
  - **イベント名**、**🗓️ 開催スケジュール枠（1行1枠）**、**📍 場所バッジ**、**🔰 対象者バッジ**、**👉 CTAボタン文言** を専用の入力欄で直感的に整えられます。

---

### Step 3: 「AI背景映像（.mp4）」または「高速静止画」で素材生成＆尺確定する
1. 画面下部のボタンから生成モードを選びます：
   - **[🎥 ステップ1：音声＋AI背景映像(.mp4)を生成]**：**Gemini Omni 1.1 Flash（`gemini-omni-1.1-flash` / Interactions API）** を使用し、各シーンの文字配置（中央・左・右）に合わせた余白と動きを持つ **10秒間の実写・3DCG風AI背景動画（`.mp4`）** を直接生成します。
   - **[⚡ 音声＋静止画で高速生成]**：コストと時間を抑えた **Gemini Flash Image（`gemini-3.1-flash-lite-image`）＋ カメラパン＆ズーム＋30fps金箔・火花パーティクル** で素早く生成します。
2. Gemini Flash TTS（`gemini-3.8-flash-lite-tts` / `gemini-3.8-flash-tts`）が各シーンの `.wav` 音声を生成し、**WAVファイルのバイト数から1ミリ秒単位の正確な再生秒数を算出**して各カットのフレーム数（30fps）を確定させます。
3. 各カード内の音声プレイヤー（`<audio>`）や背景動画プレビュー（`<video>`）を確認し、「シーン2のセリフだけ直したい」「シーン1の背景映像だけ撮り直したい」という場合は、そのカードの **[🔄 このシーンだけ音声・背景を再生成]** ボタンを押すだけで部分リテイクが可能です。

---

### Step 4: MP4書き出し（巻物・金屏風・インフォメーションボード合成）
1. 各シーンの **「📐 文字配置＆背景余白指定（中央 / 左側 / 右側）」** と **「📜 文字枠モチーフ（和紙の巻物 / 金屏風 / モダングラス）」**、および画面左側の **「🎨 ビジュアルテーマ＆フォント提案」** を好みに応じて調整できます（文字配置やモチーフ・フォントの変更は背景素材の再生成なしでそのままStep 2のレンダリングに反映されます）。
2. 画面下部の **[🎬 ステップ2：MP4動画をレンダリング出力]** を押します。
3. Remotionがヘッドレスブラウザで1フレーム単位の決定論的レンダリングを実行し、完了すると画面左下のプレビュープレイヤーで再生＆ **[⬇️ 完成MP4動画 (cm_video.mp4) をダウンロード]** から保存できます（`out/cm_video.mp4` にも出力されます）。

## 🛠️ 3. 【応用編】よくあるカスタマイズ方法

### ① 同じイベントから「汎用CM」と「日付入りCM」、および「横長」「縦長」を素早く量産するコツ
本スタジオのシナリオデータ（`scenario.json`）は、シーン4のインフォメーションボードに **日付入り用データ（`schedules` / `narrationDated`）** と **汎用CM用データ（`evergreenSchedules` / `narrationEvergreen`）** の両方を保持できます。

1. まず **`📅 日付入りピンポイント告知`** × **`🖥️ 横長 (16:9)`** でテスト生成＆MP4書き出しを行い、完成動画をダウンロードします。
2. 次に画面左上のボタンで **`♻️ 汎用CM（日付なし）`** にワンクリック切り替えします。
   - シーン1〜3の音声・背景素材はそのまま使い回せるため、**シーン4のカードにある [🔄 このシーンだけ音声・背景を再生成] だけを1回押す**だけで汎用CM用の音声尺が確定します！
3. そのまま **[🎬 ステップ2：MP4動画をレンダリング出力]** を押せば、わずか数十秒で2本目の「常設用・汎用CM」が完成します。
4. さらに **`📱 縦長ショート (9:16)`** ボタンを押して **[🎬 ステップ2：MP4動画をレンダリング出力]** を押せば、音声や背景を再生成することなく、文字サイズやカード配置が縦画面向けに自動最適化されたショート動画版（1080×1920）を即座に書き出せます。

---

### ② シーン4のインフォメーションボードの色・ロゴ・バッジデザインを変更する場所
シーン4のチラシ要約パネル（インフォメーションボード）は **`src/components/InfoBoardScene.tsx`** で実装されています。

- **カラーテーマ・グラデーションの変更**：
  `src/components/InfoBoardScene.tsx` 冒頭の `TONE_BOARD_STYLE` オブジェクト（`passionate` / `smart` / `friendly`）の `headerGradient`、`ctaGradient`、`borderGlow` を書き換えることで、ブランドカラーやコーポレートカラーに統一できます。
- **すりガラス効果・背景透過度の調整**：
  ボード外枠の `background: "rgba(10, 15, 32, 0.86)"` や `backdropFilter: "blur(20px)"` を変更することで、グラスモーフィズムの質感を調整できます。
- **ロゴ画像の追加**：
  `public/` フォルダにロゴ画像（例：`public/logo.png`）を置き、`InfoBoardScene.tsx` のヘッダー領域で `<Img src={staticFile("logo.png")} />` を配置すれば、常時イベントロゴ入りのインフォボードにカスタマイズできます。
- **シーン1〜3のデカ文字デザインの変更**：
  `src/components/ImpactHeading.tsx` でフォントサイズ、枠線、光彩エフェクト、サブバッジのアニメーションをカスタマイズできます。

---

### ③ 手元のイベント写真やバーチャル校のスクリーンショットを背景に使う方法
AI生成画像ではなく、実際の「CPAバーチャル校のスクリーンショット」や「過去のイベント風景写真」を背景に使いたい場合は以下の2通りの方法があります：

1. **Web UIから直接アップロードする（推奨）**
   - 対象シーンのカードの「背景モード」プルダウンを **`📁 手元画像アップロード`** に切り替えます。
   - 出現した **[📤 画像ファイルを選択]** ボタンから手元の画像（PNG / JPG / WebP）を選ぶだけで、自動的に `public/generated/scene{N}_custom.png` として保存・反映され、Remotion側で自動的にゆっくりズームするKen Burnsアニメーションと文字読みやすさ用の暗めオーバーレイが適用されます。
2. **ファイルを直接配置する**
   - `public/generated/` フォルダ内に任意の画像を置き、`scenario.json` の該当シーンの `"bgMode": "custom"`、`"bgFile": "generated/ファイル名.png"` に指定しても同様に利用できます。

## 💻 4. CLIコマンド一覧

Web UIを使わず、ターミナルから直接バッチ実行やRemotion Studioプレビューを行うことも可能です。

| コマンド | 説明 |
| :--- | :--- |
| `npm run studio` | **メインのWeb UI制作スタジオ（`http://localhost:3000`）を起動** |
| `npm run preview` | Remotion Studioを起動し、1フレーム単位でアニメーションやレイアウトを確認 |
| `npm run generate:mock` | APIを消費せずにダミー音声・プロシージャル背景画像を生成し、尺計測＆ `src/generated-props.json` を更新 |
| `npm run generate` | `.env` の `GEMINI_API_KEY` を使って全シーンの音声（Gemini TTS）と背景を生成し尺を確定 |
| `npm run render` | CLIから直接横長16:9の完成動画（`out/cm_video.mp4`）をレンダリング出力 |
| `npm run render:portrait` | CLIから直接縦長9:16の完成動画（`out/cm_video_portrait.mp4`）をレンダリング出力 |
